# 一级标题

段落之间使用一个空行分隔。

这是第二个段落。可以使用 _斜体_、**粗体** 和 `等宽文本`。无序列表如下：

- 第一项
- 第二项
- 第三项

编写列表时，注意列表标记之后的正文位置；嵌套内容需要保持正确的缩进。

> 引用可以这样编写。
>
> 如果需要，也可以在一段引用中包含多个段落。

原示例还演示了排版替换写法：使用三个连字符 `---` 表示长破折号，两个连字符 `--` 表示范围（例如第 12--14 章），三个点 `...` 表示省略号。是否自动转换取决于 Markdown 渲染器的配置。

Markdown 支持 Unicode 字符。☺

## 二级标题

下面是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

下面是缩进代码块：

    # 再重复一次……
    for i in 1 .. 10 { do-something(i) }

代码块前缩进四个空格。也可以使用围栏代码块，便于复制和粘贴：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

在开头的围栏后指定语言，即可让支持该语言的渲染器提供语法高亮：

```python
import time
# 快，数到十！
for i in range(10):
    # 不过也别太快
    time.sleep(0.5)
    print(i)
```

### 三级标题

下面是嵌套列表：

1. 首先准备这些食材：

    - 胡萝卜
    - 芹菜
    - 扁豆

2. 烧开一锅水。

3. 把所有食材倒入锅中，按照下面的步骤操作：

        找到木勺
        揭开锅盖
        搅拌
        盖上锅盖
        小心地把木勺架在锅柄上
        等待 10 分钟
        回到第一步（煮好后关火）

    不要碰到木勺，否则它会掉下来。

列表中的续行需要与所属条目保持正确的缩进，包括上面第三项的最后一行。

可以添加指向[网站](http://foo.bar)的链接，也可以链接到[当前文章的二级标题](#二级标题)。相对路径链接的写法是 `[本地文档](local-doc.html)`，使用时需要确保目标页面实际存在。这里还有一个脚注[^1]。

[^1]: 在这里填写脚注内容。

下面是适用于当前博客的表格写法：

| 尺码 | 材质 | 颜色 |
| --- | --- | --- |
| 9 | 皮革 | 棕色 |
| 10 | 麻帆布 | 原色 |
| 11 | 玻璃 | 透明 |

表格说明：鞋子的尺码、材质和颜色。

原文还展示了 Pandoc 的多行表格语法。不同 Markdown 渲染器对扩展语法的支持不同，在本博客中可以使用上面的管道表格表示同类内容：

| 关键词 | 说明 |
| --- | --- |
| 红色 | 日落、苹果，以及其他红色或偏红的事物。 |
| 绿色 | 树叶、青草、青蛙，以及其他绿色的事物。 |

原文中的定义列表写法如下；其显示方式取决于渲染器是否支持该扩展：

```markdown
苹果
: 适合制作苹果酱。

橙子
: 一种柑橘类水果。

番茄
: 英文单数拼写是 tomato。
```

定义项之间留一个空行，可以让源码更清晰。需要缩进的内容使用四个空格。

原文还展示了 Pandoc 的“行块”写法：

```markdown
| 第一行
| 第二行
| 第三行
```
